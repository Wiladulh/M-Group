Perangkat

Kelola perangkat Cashier dan Vending. ID registry sementara dibuat server saat provisioning; perangkat membuat hardware ID kanonis dari MAC saat boot. Hanya Device Key yang perlu dimasukkan ke WebUI lokal.

Generate Key Perangkat

Admin memilih jenis perangkat dan lokasi pemasangan. Server membuat ID registry sementara dan Device Key unik. Masukkan hanya Device Key ke WebUI lokal; perangkat membuat hardware ID kanonis dari MAC dan server mengikatnya saat registrasi pertama.

ID registry sementara hanya untuk pencatatan server. Masukkan Device Key dari server ke WebUI mini perangkat; hardware ID fisik dibuat otomatis dari MAC. Key ditampilkan satu kali; database hanya menyimpan hash key. Untuk HTTPS, masukkan CA server tepercaya pada WebUI perangkat agar sertifikat diverifikasi. Setiap perangkat memiliki WebUI lokal ber-PIN awal 19929900 dan mewajibkan penggantian sebelum konfigurasi disimpan.
