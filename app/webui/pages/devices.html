Perangkat

Kelola perangkat Cashier dan Vending. Identitas perangkat ditentukan server melalui Device Key; MAC address tidak digunakan sebagai identitas sistem.

Generate Key Perangkat

Admin memilih jenis perangkat. Server membuat Device Key unik; perangkat melakukan registrasi dan heartbeat menggunakan key tanpa mengirim MAC address atau Device ID.

Masukkan hanya Device Key ke WebUI mini perangkat. Database hanya menyimpan hash key.
