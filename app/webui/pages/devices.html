Perangkat

Kelola perangkat Cashier dan Vending. Device ID dibuat server saat provisioning dan harus dimasukkan ke WebUI lokal perangkat.

Generate Key Perangkat

Admin hanya memilih jenis perangkat dan lokasi pemasangan. Server membuat Device ID dan Device Key unik. Keduanya dimasukkan ke WebUI lokal perangkat; server mengikat ID dengan MAC saat registrasi.

Masukkan Device ID dan Device Key dari server ke WebUI mini perangkat. Key ditampilkan satu kali; database hanya menyimpan hash key. Untuk HTTPS, masukkan CA server tepercaya pada WebUI perangkat agar sertifikat diverifikasi. Cashier meminta PIN WebUI awal 19929900 dan mewajibkan penggantian sebelum konfigurasi disimpan.
