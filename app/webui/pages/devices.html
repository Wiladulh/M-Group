Perangkat

Kelola identitas perangkat Cashier dan Vending. Hardware ID dan kredensial perangkat tidak dapat diubah dari WebUI.

Device Key Manager

Buat key baru untuk satu perangkat. Key ditampilkan satu kali; salin ke konfigurasi perangkat dan jangan membagikannya.

Database hanya menyimpan hash key. Jika key hilang, generate key baru dan perbarui konfigurasi firmware perangkat.
