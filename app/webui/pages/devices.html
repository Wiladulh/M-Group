Perangkat

Kelola perangkat Cashier dan Vending. Tentukan Device Location sebelum membuat key agar setiap unit mudah dikenali.

Generate Key Perangkat

Pilih jenis perangkat dan isi Device Location terlebih dahulu. Server membuat Device Key unik yang dipakai untuk autentikasi perangkat.

Masukkan hanya Device Key ke WebUI mini perangkat. Key adalah rahasia autentikasi dan hanya ditampilkan sekali. Lokasi adalah label untuk admin, bukan kredensial keamanan.
