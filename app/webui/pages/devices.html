Perangkat

Kelola lokasi pemasangan perangkat Cashier dan Vending. ID internal tetap digunakan server untuk mengikat perangkat, key, dan transaksi.

Generate Key Perangkat

Admin hanya memilih jenis perangkat. Server membuat Device Key unik. Device ID dibuat otomatis oleh ESP32 dari MAC address dan dicatat server saat registrasi pertama.

Masukkan hanya Device Key ke WebUI mini perangkat. Device ID tidak perlu dimasukkan. Database hanya menyimpan hash key.
