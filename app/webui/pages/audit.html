Audit Transaksi

Audit terpisah untuk transaksi Cashier dan Vending. Filter tersedia per Cashier, Vending, Top Up, atau semua transaksi; periode harian, mingguan, bulanan, atau rentang manual. Laporan dapat diunduh sebagai file Excel (.xlsx).

Cashier Operator PIN

PIN operator Cashier belum disetel secara default. Atur PIN baru di sini sebelum menerima setoran Cashier.

Backup & Restore

Backup mencakup database operasional, member, perangkat, transaksi, Ledger, produk/inventory, manifest, dan checksum. Arsip native .mgroup.zip adalah format pemulihan utama; XLSX untuk pelaporan.
