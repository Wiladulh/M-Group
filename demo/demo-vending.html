2. Konfigurasi jaringan & server v2

Masukkan base URL server tanpa path API dan tanpa garis miring di akhir. Contoh LAN: http://192.168.1.10:8011
Wajib diisi jika URL memakai HTTPS. Firmware menolak HTTPS tanpa CA tepercaya dan tidak memakai TLS insecure fallback.
Device Key dibuat server dan ditampilkan satu kali. Tidak ada input Device ID atau MAC: hardware_id dibuat dari eFuse MAC dan registry_id diberikan server saat enrollment.
Belum ada konfigurasi yang dikirim.

3. Keamanan WebUI lokal

PIN awal dibuat otomatisPIN numerik 8 digit ditampilkan satu kali pada Serial Monitor saat boot pertama. Tidak ada PIN default bersama.
Sesi WebUI memakai cookie HttpOnly selama 30 menit, dengan pembatasan percobaan login. PIN lokal berbeda dari PIN member dan Device Key.

Catatan keamanan

• Device ID dan Device Key harus diterbitkan server, bukan berasal dari MAC yang dianggap sebagai rahasia.

• Simpan Device Key dengan aman; jangan tampilkan penuh setelah provisioning.

• Jika kredensial salah, tampilkan status error dan sediakan retry/reset konfigurasi.

• Pembayaran saldo harus ditolak jika server tidak dapat memverifikasi saldo dan otorisasi.
