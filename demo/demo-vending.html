2. Keamanan WebUI lokal

PIN awal firmware saat ini: 19929900. PIN wajib diganti sebelum konfigurasi disimpan. PIN baru minimal 8 karakter.

3. Konfigurasi server M-Group

Masukkan base URL server yang dapat dijangkau perangkat, tanpa path API dan tanpa garis miring di akhir. Contoh: http://192.168.1.10:8011
HTTPS ditolak jika CA tepercaya belum dikonfigurasi. HTTP hanya untuk jaringan LAN tepercaya.
ID dibuat server dan tetap sama saat hardware diganti. MAC hanya dipakai untuk mengikat hardware, bukan sebagai Device ID.
Device Key ditampilkan satu kali saat provisioning di dashboard. Jangan gunakan key perangkat lain atau token admin.
Belum ada perubahan. Isi kredensial yang diterbitkan server.

Catatan keamanan

• Device ID dan Device Key harus diterbitkan server, bukan berasal dari MAC yang dianggap sebagai rahasia.

• Simpan Device Key dengan aman; jangan tampilkan penuh setelah provisioning.

• Jika kredensial salah, tampilkan status error dan sediakan retry/reset konfigurasi.

• Pembayaran saldo harus ditolak jika server tidak dapat memverifikasi saldo dan otorisasi.
