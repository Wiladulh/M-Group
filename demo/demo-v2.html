Pengaturan Administrator

Pengelolaan password dan sesi WebUI.

Ganti Password Admin

Akun utama menggunakan username tetap admin. Masukkan password lama, password baru, dan konfirmasi password baru.

Simulasi demo hanya menyimpan status login di memori halaman. Password tidak dikirim ke server dan tidak disimpan sebagai hash. Implementasi keamanan sebenarnya tersedia di WebUI server.

Sesi WebUI

Sesi server menggunakan cookie HttpOnly, batas idle 30 menit, dan maksimum 12 jam.
