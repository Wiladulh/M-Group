Generate Key Perangkat

Admin hanya memilih jenis perangkat. Server membuat Device Key unik. Perangkat mengirim hardware_id saat enrollment; server menetapkan registry_id. Database hanya menyimpan hash key.

Device Key baru hanya ditampilkan pada proses provisioning.

Masukkan hanya Device Key ke WebUI konfigurasi perangkat. hardware_id tidak perlu diketik manual. Penggantian board dilakukan melalui aksi Ganti hardware.

Pengaturan

Metode autentikasi dan kontrol keamanan administrator.

Konfigurasi Administrator

Clean-room v2 menggunakan satu Admin API Token dari environment server. Tidak ada akun username/password atau perubahan kredensial melalui WebUI.

Metode autentikasi
Bearer token
Penyimpanan browser
Session-only
Pengelolaan token
Server secret
Token dikelola melalui secret MGROUP_ADMIN_TOKEN. Rotasi token memerlukan perubahan secret dan restart terencana.

Gerbang keamanan sebelum produksi

  • Gunakan HTTPS/reverse proxy dan batasi akses jaringan ke dashboard.
  • Simpan MGROUP_ADMIN_TOKEN dan MGROUP_DEVICE_KEY_PEPPER di secret manager.
  • Rotasi device key melalui halaman Perangkat dan simpan key baru pada perangkat terkait.
  • Jalankan uji restore backup dan rekonsiliasi ledger sebelum cutover.
  • Pertamini tetap nonaktif sampai spesifikasi hardware dan keselamatannya disetujui.
