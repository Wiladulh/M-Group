Konfigurasi lokal perangkat

WebUI perangkat diakses lewat alamat IP DHCP perangkat. Device ID dan Device Key diterbitkan server; jangan menggunakan MAC sebagai kredensial rahasia.

Perangkat & Provisioning

Server menerbitkan Device Key unik; perangkat membuat hardware ID kanonis dari MAC dan mengikat identitas saat registrasi pertama. Key rahasia hanya ditampilkan saat dibuat.

Provisioning perangkat

Audit transaksi

Filter sumber, metode, perangkat, member, status dan periode; XLSX di WebUI operasional dihasilkan oleh server.

Audit keamanan & sistem

Perubahan akun admin, hak akses, status perangkat, rotasi/pencabutan key, dan peristiwa sistem.

Pengaturan sistem

Pengaturan operasional memerlukan login admin dan koneksi ke backend.

Catatan keamanan

  • Saldo server adalah sumber kebenaran.
  • Saldo cache perangkat harus disinkronkan dan tidak boleh mengizinkan transaksi saat saldo tidak dapat diverifikasi.
  • Device Key bersifat rahasia; jangan ditampilkan kembali setelah provisioning.
  • Backup/restore nyata wajib divalidasi di server sebelum produksi.
