Audit & Backup

Jejak audit, laporan transaksi, dan pemulihan native M-Group.

Recovery policy: backup .mgroup.zip adalah arsip pemulihan. Laporan Excel berikut digunakan untuk pemeriksaan operasional; file demo berisi data contoh browser, bukan transaksi produksi.

Ekspor laporan siap diperiksa

Excel · nama file otomatis berisi waktu ekspor dan periode
Contoh nama: vend-HHMMDDMMYY-1d.xlsx
Format waktu: jam-menit-tanggal-bulan-tahun.
Catatan demo: rentang laporan baru menjadi pilihan contoh; data belum difilter menurut tanggal historis. Produksi akan mengambil transaksi sesuai periode dari server.
