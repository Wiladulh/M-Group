Audit Transaksi

Audit terpisah untuk transaksi Cashier dan Vending. Filter tersedia per hari, minggu, atau bulan. Laporan dapat diunduh sebagai file Excel (.xlsx).

Audit Event

PIN operator dikelola per terminal pada menu Cashier agar identitas operator dan rekening settlement selalu terikat pada perangkat tertentu.

Backup & Restore

Backup mencakup database operasional, member, perangkat, transaksi, Ledger, produk/inventory, manifest, dan checksum. Arsip native .mgroup.zip adalah format pemulihan utama; XLSX untuk pelaporan.
