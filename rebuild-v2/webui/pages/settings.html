Konfigurasi Administrator

Clean-room v2 saat ini menggunakan satu Admin API Token dari environment server. Tidak ada akun username/password atau perubahan kredensial melalui WebUI pada implementasi ini; jangan tampilkan token kembali setelah login.

Metode autentikasi
Bearer token
Penyimpanan browser
Session-only
Pengelolaan token
Server secret / deployment
Token dikelola melalui secret MGROUP_ADMIN_TOKEN di lingkungan server. Rotasi token memerlukan perubahan secret dan restart terencana.

Gerbang keamanan sebelum produksi

  • Gunakan HTTPS/reverse proxy dan batasi akses jaringan ke dashboard.
  • Simpan MGROUP_ADMIN_TOKEN dan MGROUP_DEVICE_KEY_PEPPER di secret manager; jangan masukkan ke repository.
  • Rotasi device key melalui halaman Perangkat dan simpan key baru pada perangkat terkait.
  • Jalankan uji restore backup dan rekonsiliasi ledger sebelum cutover.
  • Fitur Pertamini tetap nonaktif sampai spesifikasi hardware dan keselamatannya disetujui.
