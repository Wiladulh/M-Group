Akun Administrator

Ganti password dengan memasukkan password saat ini dan password baru dua kali. Password baru minimal 12 karakter.

Keamanan Server

  • Login admin menggunakan username dan password; sesi disimpan dalam cookie HttpOnly dan tidak mengekspos token ke JavaScript.
  • Gunakan HTTPS/reverse proxy dan batasi akses jaringan ke dashboard.
  • Simpan MGROUP_DEVICE_KEY_PEPPER sebagai secret server; jangan masukkan ke repository.
  • Rotasi Device Key melalui halaman Perangkat dan simpan key baru pada perangkat terkait.
  • Jalankan uji restore backup dan rekonsiliasi ledger sebelum cutover.
  • Fitur Pertamini tetap nonaktif sampai spesifikasi hardware dan keselamatannya disetujui.
