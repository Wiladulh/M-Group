Perangkat

Kelola perangkat Cashier dan Vending. Registry ID adalah identitas logis tetap dari server; hardware_id dibuat dari eFuse MAC. Gunakan Ganti hardware saat board rusak agar registry ID dan konfigurasi slot tetap sama, sementara key lama langsung dicabut.

Generate Key Perangkat

Admin hanya memilih jenis perangkat. Server membuat Device Key unik. Perangkat mengirim hardware_id saat enrollment; server menetapkan registry_id.

Masukkan hanya Device Key ke WebUI konfigurasi perangkat. hardware_id dibuat otomatis dari eFuse MAC. Jika board diganti, gunakan aksi Ganti hardware untuk menerbitkan key baru dan membuka enrollment ulang pada registry ID yang sama. Database hanya menyimpan hash key.
