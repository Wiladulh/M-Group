Perangkat

Kelola perangkat Cashier dan Vending. Identitas fisik hardware_id dibuat oleh perangkat dan diregistrasikan dengan registry_id server.

Generate Key Perangkat

Admin hanya memilih jenis perangkat. Server membuat Device Key unik. Perangkat mengirim hardware_id saat enrollment; server menetapkan registry_id.

Masukkan hanya Device Key ke WebUI konfigurasi perangkat. hardware_id tidak perlu diketik manual oleh admin. Database hanya menyimpan hash key.
